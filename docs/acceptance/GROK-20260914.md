## HIAI-UI-T04

### Cause

Vite SSR in finance (and any app that `import { EmptyState } from "@hiai-gg/hiai-ui"`) loaded `dist/index.js`, which statically re-exported `HiAiEditor`, which imports `svelte-tiptap`. That package's `"."` export has only `types` + `svelte` — no `default`/`import` — so Vite reports `svelte-tiptap has no known '.' export`.

Wildcard `"./components/*"` also mapped `badge`/`card`/`checkbox`/`label`/`radio-group`/`textarea`/`confirm-dialog` `/index` specifiers without a `.js` target.

### After

- `src/editor.ts` is `@hiai-gg/hiai-ui/editor` (`HiAiEditor`, toolbar, markdown helpers). Main barrel does not mention them.
- Every `src/components/ui/<name>/index.ts` has `package.json` `./components/ui/<name>/index` → `./dist/components/ui/<name>/index.js`.
- `classifyHiaiUiPin` treats exact `0.1.3` and `npm:@hiai-gg/hiai-ui@0.1.3` as portable; `^0.1.1` and `#main` as forbidden-float; sibling `file:` as dev-only.
- `hiaiUi()` from `@hiai-gg/hiai-ui/vite` sets `optimizeDeps.exclude` and `ssr.noExternal` for `svelte-tiptap` (still required for editor hosts).

Playground still imports `HiAiEditor` via a relative path, so it does not need the new subpath.

### Breaking (unpublished)

`import { HiAiEditor } from "@hiai-gg/hiai-ui"` will fail after the next owner tag. hiai-post (`PostEditor.svelte`) must switch to `@hiai/ui/editor`. npm `0.1.3` is unchanged until that tag.
