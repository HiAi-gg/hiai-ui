# hiai-ui Tasks — 2026-07-08

> Generated by hiai-admin T1 audit. Tasks for adding/exporting missing primitives.

## Background

During hiai-admin dropdown/menu/select audit (T1), we found:
- 15 files in hiai-admin use(d) native `<select>` — 13 replaced with `@hiai/ui` Select via deep-path imports
- 6 custom dropdowns in EditorToolbar.svelte (color picker, emoji picker, table inserter, heading selector, text alignment, link inserter)
- 1 custom popover in NotificationBell.svelte
- All bespoke cases use manual state management and aria — no consistent design system

## Missing Primitives

### 1. Popover (HIGH priority)
- **Need:** Custom popovers in EditorToolbar and NotificationBell
- **Evidence:** EditorToolbar.svelte has 6 custom dropdowns; NotificationBell.svelte has 1 popover
- **bits-ui available:** `Popover` is shipped in bits-ui v2.18.1
- **Work estimate:** ~4h (wrap Popover from bits-ui, add dark/light tokens, add a11y)

### 2. Command / Combobox (MEDIUM priority)
- **Need:** Searchable command palette or combobox for editor commands
- **Evidence:** EditorToolbar heading selector and emoji picker would benefit from combobox
- **bits-ui available:** bits-ui has `Command` primitive
- **Note:** Combobox builds on Command + Popover

### 3. ContextMenu / Menubar (LOW priority)
- **Need:** Right-click context menus
- **bits-ui available:** bits-ui has `ContextMenu`
- **Note:** Not currently used in hiai-admin but would be nice for DataTable row actions

## Barrel Export Decision

Per AGENTS.md convention, primitives in `src/components/ui/` remain **deep-path only** (no barrel export). This is by design for tree-shaking. The package.json exports map already supports:
- `./components/ui/select/index`
- `./components/ui/dropdown-menu/index`

Consumers use `import { X } from '@hiai-gg/hiai-ui/components/ui/select/index'`

**No change needed.** But add a note in AGENTS.md clarifying that all new primitives follow this deep-path rule.

## Existing Select/DropdownMenu — Verified Working

- `@hiai/ui/components/ui/select/index` — exports SelectRoot, SelectTrigger, SelectValue, SelectContent, SelectItem, SelectGroup, SelectSeparator
- `@hiai/ui/components/ui/dropdown-menu/index` — exports DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuItem, DropdownMenuSeparator, DropdownMenuGroup, DropdownMenuSub

## Storybook / Demo Gap

Currently hiai-ui has **no Storybook stories** or demo pages. Quality gap:
- Stories would accelerate adoption and catch visual regressions
- Add stories for: Button, Card, Select, DropdownMenu, Dialog, Tabs, Switch, Input
- Effort: ~2-3d for initial setup + critical components
